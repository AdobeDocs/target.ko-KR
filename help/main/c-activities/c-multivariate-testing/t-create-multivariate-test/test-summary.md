# 테스트 요약([!UICONTROL 다변량 테스트]) {#mvt-test-summary}

>[!BEGINSHADEBOX]

**이 페이지에서:** 계속하기 전에 구성을 검토할 수 있도록 **[!UICONTROL 다변량 테스트]**&#x200B;의 테스트 요약에 표시되는 내용을 알아봅니다.

>[!ENDSHADEBOX]

**[!UICONTROL 타깃팅]** 페이지에서 [!DNL Adobe Target] **[!UICONTROL 다변량 테스트]**&#x200B;에 대한 시각적 개요를 제공합니다. 이 요약을 검토하면 목표 및 설정을 설정하기 전에 테스트 구성을 확인할 수 있습니다.

![테스트 요약 대화 상자](/help/main/c-activities/c-multivariate-testing/t-create-multivariate-test/assets/summary-new.png)

테스트 요약에는 다음이 표시됩니다.

* 테스트 이름입니다.
* URL입니다.
* 청중. 사용 가능한 대상자 목록에서 다른 대상자를 선택하려면 대상자를 클릭하십시오.
* 알고리즘. 사용 가능한 유일한 알고리즘은 **[!UICONTROL 전체 계승]**&#x200B;입니다. 알고리즘 이름은 정보 제공 목적으로 제공되므로, 사용 중인 알고리즘을 알 수 있습니다.
* 포함 및 제외된 경험의 수입니다.

테스트 구성에 만족하면 **[!UICONTROL 다음]**&#x200B;을 클릭합니다. **[!UICONTROL 목표 및 설정]** 페이지가 열립니다.

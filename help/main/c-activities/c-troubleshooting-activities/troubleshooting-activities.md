# 문제 해결 활동 시작 {#troubleshooting-activities}

>[!BEGINSHADEBOX]

**이 페이지에서:** [!DNL Adobe Target] 활동이 사이트에 나타나지 않거나 예상대로 작동하지 않는 경우 일반적인 문제에 대한 해결 방법을 찾으십시오.

>[!ENDSHADEBOX]

몇 가지 이유로 인해 [!DNL Adobe Target] 활동이 사이트에 표시되지 않을 수 있습니다. 다음 문제와 제안된 해결 방법을 사용하여 원인을 파악하고 수정 사항을 적용합니다.

>[!NOTE]
>
>다음 문제 해결 정보 외에 추가 문제 해결 주제, FAQ 및 [!DNL Adobe Target]의 활동 및 기능 문제 해결에 대한 기타 유용한 정보를 보려면 [Target 문제 해결](/help/main/r-troubleshooting-target/troubleshooting-target.md)을 참조하십시오.

## 활동이 예상대로 표시되지 않습니다. {#not-displayed}

+++ 기본 컨텐츠가 표시됩니다.

활동이 완료되고 활성화되었는지 확인합니다.

+++

</br>

+++ 활동이 라이브가 아님

**유효성 검사:** **[!UICONTROL 개요]** 탭에서 활동이 비활성 상태인지 초안으로 표시되어 있는지 확인하십시오.

**옵션:**

* 활동을 활성화합니다.
* 미리 보기 링크를 사용하여 비활성 활동을 표시합니다.

+++

</br>

+++ 대상 타깃팅 조건에 적합하지 않습니다.

**유효성 검사:** **[!UICONTROL 개요]** 페이지에서 타깃팅 조건을 검토하십시오.

**옵션:**

* 대상에 적합한 후 다시 시도하십시오.
* 미리보기 링크를 사용하여 타겟팅 조건을 우회합니다.

+++

</br>

+++ 페이지가 페이지 타깃팅 조건에 적합하지 않습니다

**유효성 검사:** **[!UICONTROL 개요]** 페이지에서 페이지가 타깃팅 조건을 벗어나는지 확인하십시오.

**옵션:**

* **[!UICONTROL 시각적 경험 작성기]**(으)로 이동한 다음 URL > 고급 > 현재 페이지를 클릭합니다.

+++

</br>

+++ 새 경험이 아닌 이전 경험이 표시됩니다

**유효성 검사:** 다음 옵션 중 하나를 시도한 다음 환경을 다시 보십시오.

**옵션:**

* 캐시와 쿠키를 지운 후 다시 시도하십시오.
* 다른 브라우저를 사용해 보십시오.
* 비공개 또는 시크릿 모드를 사용합니다.

+++

</br>

+++ 활동 설정 이후 페이지 구조가 변경됨

**유효성 검사:** 기존 활동에 대한 **[!UICONTROL 시각적 경험 작성기]**(으)로 이동하여 선택기(또는 구조)가 변경되었음을 나타내는 경고 메시지를 찾으십시오.

**옵션:**

* 활동을 다시 빌드합니다.

페이지 수정이 [!DNL Target]의 콘텐츠 표시 기능에 어떻게 영향을 미치는지에 대한 자세한 내용은 [페이지 수정 시나리오](/help/main/c-experiences/c-visual-experience-composer/r-troubleshoot-composer/vec-scenarios.md)를 참조하십시오.

+++

</br>

+++ 페이지 구조는 페이지 로드 중(런타임에) 수정됩니다.

**유효성 검사:** 개발자에게 문의하십시오.

**참고:** [!DNL Target]에서 활동 변경 내용을 적용해야 하는 위치를 인식하려면 같은 클래스의 요소를 동적으로 삽입하거나 형제 클래스의 클래스를 동적으로 수정하지 마십시오.

**옵션:**

* ID를 사용하여 테스트된 각 요소를 고유하게 식별하도록 페이지 코드를 업데이트합니다.
* 위에서 설명한 대로 클래스 또는 동일 수준의 요소들을 동적으로 수정하지 마십시오.

페이지 수정이 [!DNL Target]의 콘텐츠 표시 기능에 어떻게 영향을 미치는지에 대한 자세한 내용은 [페이지 수정 시나리오](/help/main/c-experiences/c-visual-experience-composer/r-troubleshoot-composer/vec-scenarios.md)를 참조하십시오.

+++

</br>

+++ 다른 활동이 동일한 페이지에서 실행 중입니다.

**유효성 검사:** **[!UICONTROL 충돌]** 탭을 사용하여 다른 작업이 실행 중인지 확인하십시오.

**참고:** **[!UICONTROL 충돌]** 탭이 템플릿 테스트 모듈에서 작동하지 않습니다.

**옵션:**

* 이 활동의 우선순위를 높입니다.
* 다른 활동의 우선 순위를 낮춥니다.
* 다른 활동을 비활성화합니다.

+++

## 사용자, API 및 UI {#users-api-ui}

+++ [!DNL Target] UI를 사용하여 활동을 만들었는데, API를 통해 업데이트할 수 없습니다

[!DNL Target] UI를 사용하여 만든 활동은 [!DNL Target] UI를 통해 업데이트해야 합니다. API를 통해 만든 활동은 API를 통해 업데이트해야 합니다. 예를 들어 API를 사용하여 활동을 만들었지만 나중에 [!DNL Target] UI를 통해 활동을 편집한 경우 일부 변경 내용이 업데이트되지는 않습니다. 모든 변경 사항은 백엔드에 저장되며 다른 API 호출을 통해 업데이트할 수 있습니다.

활동을 만드는 데 사용한 것과 동일한 방법(UI 또는 API)을 사용하여 활동을 업데이트하는 것이 좋습니다.

+++

</br>

+++ 최근 [!DNL Target]에 추가되었지만 활동을 만들 수 없습니다.

**유효성 검사:** **[!UICONTROL 활동 만들기]**&#x200B;를 클릭합니다. 이 선택 사항을 사용할 수 없다면, 활동을 만들기에 충분한 권한이 없을 가능성이 큽니다.

**옵션:**

[!DNL Target]에서 사용자로 추가된 후 활동을 만들려면 **[!UICONTROL 승인자]** 역할이 필요합니다.

* 계정 관리자에게 승인자로 지정해 달라고 요청하십시오.
* 관리자인 경우 [!DNL Target]의 **[!UICONTROL 관리]** > **[!UICONTROL 사용자]**&#x200B;에서 자신에게 **[!UICONTROL 승인자]** 역할을 지정하십시오. [자신에게 승인자 역할 할당](/help/main/administrating-target/start-target.md#task_15CAA437A71444E2932B333D5E66A3C7)을 참조하세요.

+++

</br>

+++ [!DNL Target] API를 사용하여 활동을 활성화했지만 활동이 [!DNL Target] UI에서 [!UICONTROL 비활성] 상태로 표시됩니다

[!DNL Target] API를 사용하여 UI 외부에서의 활동 활성화와 같은 특정 작업을 수행하면 업데이트가 UI로 전파되는 데 최대 10분이 걸릴 수 있습니다.

+++

</br>

+++ 프로필 스크립트를 삭제하면 오류 메시지가 나타납니다

**유효성 검사:** [!DNL Target]에서 프로필 스크립트를 삭제하면 &quot;프로필 스크립트를 삭제하지 못했습니다.&quot;라는 오류 메시지가 표시됩니다.

**옵션:**

다음 중 하나를 수행하십시오.

* 프로필 스크립트를 다시 삭제합니다. 성공 메시지가 나타납니다.
* [!DNL Target] 가져오기가 실행될 때까지 약 10분 정도 기다리십시오. 가져오기에서 프로필 스크립트 목록을 업데이트합니다.

+++

## 호출 및 전환 {#calls-and-conversion}

+++ 일부 ajax [!DNL Target] 호출이 작동하지 않습니다.

**참고:** 이름은 같지만 매개 변수가 다른 여러 개의 ajax [!DNL Target] 호출이 같은 페이지에서 작동하지 않습니다. 첫 번째 호출만 수행됩니다.

+++

</br>

+++ 활동 전환 후 방문자가 어떤 경험도 하지 않습니다

드문 경우지만 방문자에게 경험을 제공할 수 있는 활동의 전환 지표가 활동 자격과 동일한 요청으로 전송되는 경우, 방문자는 요청이 전송된 후 어떤 경험에도 있지 않을 수 있습니다. 이 경우 방문자에게 기본 컨텐츠가 표시되고 토큰을 통해 캡처된 경험 ID는 -1입니다. [!DNL Adobe]은(는) 동일한 [!DNL Target] 요청에서 활동 자격 및 전환을 보내지 않는 것이 좋습니다.

동일한 요청에서 두 지표를 모두 전송하려면 **[!UICONTROL 고급 설정]**&#x200B;을 사용하여 방문자가 전환 후에도 동일한 경험을 유지하도록 지정할 수 있습니다.

+++

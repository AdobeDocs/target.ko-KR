# 캡처 점수 {#capture-score}

>[!BEGINSHADEBOX]

**이 페이지에서:** 캡처 점수 참여 지표에서 방문의 점수를 계산하는 방법과 점수를 페이지에 할당하는 방법을 알아봅니다.

>[!ENDSHADEBOX]

[!DNL Adobe Target]의 캡처 점수 참여 지표는 방문자가 사이트에서 보는 페이지에 할당된 값을 기반으로 집계된 점수를 계산합니다. 점수는 방문자가 활동의 첫 번째 디스플레이 [!DNL Target] 요청을 처음 본 지점에서 시작됩니다.

다음 예제에서는 고양이 이미지가 있는 경험과 개 이미지가 있는 경험 두 개를 테스트하는 활동에서 점수를 계산하는 방법을 보여 줍니다.

![각 페이지에 대한 점수가 있는 고양이 경험 방문의 페이지 흐름](assets/example_score.png)

이 예에서는 첫 번째 방문자가 고양이 경험을 봅니다. 글로벌 [!DNL Target] 요청이 페이지 값을 기준으로 페이지 점수를 전달한다고 가정해 봅니다. 마케터가 **모든 Target 요청**&#x200B;과(와) 연결된 성공 지표에서 페이지 수 계산 참여를 캡처한 경우, 고양이 이미지를 둘러싼 표시 요청 후에 표시되는 모든 요청에 대해 방문 점수가 누적됩니다.

1면은 점수에 1을 더하고, 2면은 0.25, 3면은 0.10, 4면은 0.10으로 총 1.45이다. 이 합계는 통화 또는 포인트로 해석할 수 있습니다. 별도의 방문에서 방문자는 개 경험을 봅니다. 이 방문자는 더 적은 페이지를 보지만, 방문자가 더 중요한 페이지를 열람했기 때문에 점수는 다른 방문보다 큰 2.10입니다.

다음 페이지 흐름에 설명된 대로 adbox와 리디렉터를 전달하여 획득 비용 및 제휴 링크 매출을 고려할 수 있습니다. 이 예제에서 문서 페이지의 [!DNL Target] 요청은 모두 알려진 CPM을 나타낼 수 있는 점수를 전달합니다.

![획득 비용 및 제휴 링크 수익이 점수로 전달된 페이지 흐름](assets/example_score2.png)

## 페이지 점수 할당

페이지의 가치에 따라 사이트의 임의 페이지에 값을 할당할 수 있습니다. 예를 들어 요리 사이트는 경험 섹션보다 기능 문서 페이지에서 더 많은 금액에 광고를 판매할 수 있습니다. 그러면 기능 문서가 경험 섹션보다 더 중요합니다. 페이지 점수를 통해 방문의 전체 &quot;값&quot;을 개발할 수 있으므로, 더 많은 기능 문서를 읽는 사람은 경험만 보는 사람보다 더 많은 &quot;점수&quot;를 받습니다.

다음 두 가지 방법으로 페이지에 점수를 할당할 수 있습니다.

* [!DNL Target] 요청에서 `mboxPageValue` 매개 변수를 만듭니다.

  예: `('global_mbox', 'mboxPageValue=10');`

  해당 [!DNL Target] 요청이 있는 페이지를 볼 때마다 지정된 값이 점수에 추가됩니다. 페이지의 여러 요청에 점수 값이 포함된 경우 페이지의 점수는 모든 요청 값의 합계입니다. `mboxPageValue`은(는) 참여 점수를 캡처하기 위해 [!DNL Target] 요청에서 값을 전달하는 데 사용되는 예약된 매개 변수입니다. 양수 값과 음수 값을 전달할 수 있습니다. 합계는 각 방문이 끝날 때 계산되어 방문의 총 점수를 결정합니다.

* 페이지의 URL에 `?mboxPageValue=n` 매개 변수를 전달합니다.

  예: `https://www.mydomain.com?mboxPageValue=5`

  지정한 값이 페이지의 각 [!DNL Target] 요청에 대한 점수에 추가됩니다. 예를 들어 매개 변수 `?mboxPageValue=10`을(를) 전달하고 페이지에 세 개의 [!DNL Target] 요청이 있는 경우 페이지의 점수는 30입니다.

>[!NOTE]
>
>카운터는 시작 요청이 아닌 활동의 첫 번째 표시 요청으로 시작하며, 해당 요청 위에 있는 [!DNL Target]개의 요청은 점수에 포함되지 않습니다. 예를 들어, 표시 요청이 없는 홈 페이지에 활동을 입력한 다음 표시 요청이 포함된 카탈로그 페이지에 연결하는 경우, 카탈로그 페이지로 이동하면 카운터가 시작됩니다.

가장 좋은 방법은 [!DNL Target] 요청에 값을 할당하는 것입니다. 이 방법을 사용하면 각 요청의 내용에 따라 측정하는 값을 정확하게 지정할 수 있습니다.

>[!NOTE]
>
>간편하게 유지 관리할 수 있도록 일부 조건부 JavaScript 논리를 사용하여 [!DNL at.js] 파일에서 사이트의 페이지 점수값 할당을 구성할 수 있습니다. 이 방법을 사용하면 페이지에 코드를 더 추가할 필요가 없습니다. 도움이 필요한 경우 계정 컨설턴트에게 문의하십시오.

두 가지 방법을 결합할 수 있지만 이 경우 예상보다 높은 점수가 발생할 수 있습니다. 예를 들어 세 개의 [!DNL Target] 요청에 각각 10을 할당하고 네 번째 요청에 점수를 매기지 않은 다음 URL 매개 변수 `?mboxPageValue=5`을(를) 전달합니다. 페이지 점수는 값이 지정된 3개의 요청에 대해 50: 30이고 URL 매개 변수에 대해 20을 더한 값(페이지의 4개 요청에 대해 각각 5개)입니다.

비용이 들거나 방문자가 보지 않는 것이 좋은 특정 페이지에 대해 음수 값을 전달할 수도 있습니다. 음수 값은 전체 점수에도 영향을 줍니다. 이 기술은 방문자가 광고에서 도달하는 페이지에서 사용할 수 있으므로 CPC의 양을 알 수 있습니다. 방문자가 전화하거나 지원을 요청할 수 있는 지원 또는 연락처 페이지에서도 사용할 수 있습니다.
